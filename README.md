| **Исследование рынка недвижимости и оценка стоимости жилья (Санкт-Петербург)** | Проведён полный цикл EDA архива объявлений (23k+ объектов) для выявления драйверов цены и построения логики автоматической оценки. Выполнена глубокая очистка данных: устранение аномалий в ценах и площадях, нормализация геоданных и названий локаций. Результаты визуализированы в виде интерпретируемых графиков для принятия решений по ценообразованию и детекции мошеннических схем | **python**<br>pandas, numpy, matplotlib, seaborn |
