# Портфолио проектов Data Science & Analytics

Добро пожаловать в мое портфолио! Здесь собраны ключевые проекты, демонстрирующие мой подход к решению бизнес-задач с помощью данных.

Ниже представлена детальная таблица с описанием проектов, использованными инструментами и полученными бизнес-результатами.

| Проект | Описание | Инструменты |
|--------|----------|-------------|
| **Исследование рынка недвижимости и оценка стоимости жилья (Санкт-Петербург)** | Проведён полный цикл EDA архива объявлений (23k+ объектов) для выявления драйверов цены и построения логики автоматической оценки. Выполнена глубокая очистка данных: устранение аномалий в ценах и площадях, нормализация геоданных и названий локаций. Сформированы новые признаки: цена за м², тип этажа, сезонность публикации. **Ключевые инсайты для бизнеса:** выявлена прямая зависимость цены от расстояния до центра (падение после 5 км), сезонный рост спроса весной/летом и дисконт 10–15% для квартир на первом/последнем этажах. Результаты визуализированы в виде интерпретируемых графиков для принятия решений по ценообразованию и детекции мошеннических схем | **python**<br>pandas, numpy, matplotlib, seaborn |
| **Статистический анализ данных сервиса аренды самокатов GoFast** | Проведён комплексный статистический анализ данных сервиса аренды самокатов: изучение поведения пользователей, сравнение групп с подпиской Ultra и без подписки, оценка помесячной выручки. Проверены статистические гипотезы о времени поездок, расстоянии и выручке с использованием t-тестов. Рассчитаны вероятности для маркетинговых задач: минимальное количество промокодов для акции (биномиальное распределение) и вероятность открытия push-уведомлений (нормальная аппроксимация) | **python**<br>pandas, numpy, matplotlib, seaborn, scipy |
| **Исследование рынка видеоигр и прогнозирование трендов (проект «Стримчик»)** | Проведён комплексный анализ исторических данных о продажах игр (2014–2016 гг.) для планирования закупок на 2017 год. Изучена динамика продаж по платформам (лидеры: PS4, XOne, 3DS) и жанрам (Shooter, Action, Sports). Оценено влияние рейтингов: выявлена умеренная корреляция оценок критиков с продажами (в отличие от пользовательских оценок). Проверены статистические гипотезы (t-тесты) о различии средних рейтингов платформ и жанров. Сформированы портреты пользователей ключевых регионов (NA, EU, JP) и даны рекомендации по фокусу на конкретных платформах и жанрах для максимизации прибыли | **python**<br>pandas, numpy, matplotlib, seaborn, scipy |
| **Линейные модели в машинном обучении (прогнозирование удоя и вкуса молока)** | Разработаны модели машинного обучения для помощи фермеру в выборе коров: линейная регрессия для прогноза годового удоя (R² = 0.8111) и логистическая регрессия для классификации вкуса молока (Recall = 0.9610). Проведена предобработка данных (обработка выбросов, кодирование категориальных признаков, масштабирование), исследовательский анализ (EDA), корреляционный анализ и оптимизация порога классификации. На основе моделей отобрано 5 коров, удовлетворяющих критериям (удой ≥ 6000 кг и вкусное молоко) | **python**<br>pandas, numpy, matplotlib, seaborn, scikit-learn, scipy |
| **Сегментация покупателей интернет-магазина и прогнозирование оттока** | Проведён полный цикл анализа данных для выявления клиентов с риском снижения активности. Выполнена предобработка 4 датасетов, исследовательский анализ с использованием корреляции $\phi_K$ (библиотека `phik`) и устранение мультиколлинеарности. Обучены и сравнены модели классификации (KNN, Decision Tree, Logistic Regression, SVC) с подбором гиперпараметров через `GridSearchCV`. Лучшая модель (**SVC**, ROC-AUC ≈ 0.91) проинтерпретирована с помощью `SHAP` для определения ключевых факторов оттока. На основе прогноза вероятности снижения активности и уровня прибыли выполнена кластеризация клиентов на 6 сегментов и разработаны персонализированные маркетинговые стратегии для удержания наиболее ценных групп | **python**<br>pandas, numpy, matplotlib, seaborn, scikit-learn, phik, shap |
| **HR-Аналитика: Прогнозирование удовлетворённости и оттока сотрудников** | Разработана двухэтапная система поддержки HR-решений. На первом этапе построена регрессионная модель (**RandomForestRegressor**) для предсказания уровня удовлетворённости (`job_satisfaction_rate`) с метрикой **SMAPE = 13.31%** (цель ≤15%). Предсказанный уровень удовлетворённости использован как новый признак во второй задаче. На втором этапе создана модель классификации (**GradientBoostingClassifier**) для прогноза увольнения (`quit`) с метрикой **ROC-AUC = 0.92** (цель ≥0.91). Проведён полный цикл: очистка данных, кодирование признаков (OneHot/Ordinal), подбор гиперпараметров через `GridSearchCV` и интерпретация результатов. Выявлены ключевые факторы риска: низкая оценка руководителя, отсутствие повышений и низкий уровень удовлетворённости | **python**<br>pandas, numpy, matplotlib, seaborn, scikit-learn, phik |
